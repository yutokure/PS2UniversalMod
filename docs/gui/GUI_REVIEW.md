## 2. 日本語対応

* `gui/camera_controller/i18n.py` に辞書ベースのカタログ（約 90 キー）。
* ウィジェットは生成時に自分自身を登録し、言語変更時に `_retranslate()` が一括で貼り替える。
  **再起動は不要**。
* 選択言語は `AppSettings.language` としてゲーム別に保存（既定 `ja`）。
* 接続欄に「表示言語」コンボを追加（日本語 / English）。
* Qt Linguist（.ts/.qm）を使わないので、ビルド工程なしで `python run_gui.py` がそのまま動く。

## 3. わかりやすさ・直感性の評価

### 良い点

* **接続欄が最上段**で、PCSX2 / ゲーム / シリアル / アダプタ / 実行状態 / パッチ状態が一目で分かる。
* **「視線パッチ」を独立した行**にしたことで、「動かない」ではなく「未適用」と原因が読める。
  未適用時は橙、適用時は緑で色分け。
* **モードがラジオボタン**で、いま何をしているかが常に見える。
* **スライダーと数値入力が常に同期**（`FloatSlider`）。片方だけ操作しても破綻しない。
* **Debug 欄にカメラ視点・注視点・プレイヤー基準点**が並び、注視点が「プレイヤー基準点 + look_height」に
  なっていることが数値で確認できる。
* 破壊的操作（元のカメラに戻す）が独立ボタンで、誤操作しても復帰できる。

### 改善した点

* 「注視点の高さ」を独立スライダーにした（フレーミングの要）。
* 「視線パッチ」に説明ツールチップを追加。
* プリセット combo にツールチップ（何を選ぶ欄か不明だった）。

### まだ分かりにくい点（未対応）

| 項目 | 内容 | 提案 |
|---|---|---|
| U1 | プリセット combo にラベルが無い（ボタン列に埋もれている） | 「プリセット」見出しを付けるか、保存/読込を1つのメニューに統合 |
| U2 | `Input source` の選択肢 `auto/xinput/keyboard/scripted` が技術用語のまま | 「自動 / ゲームパッド / キーボード / スクリプト」へ翻訳 |
| U3 | Free Camera の XYZ を直接入力する欄が無い（有効化時に現在の視点を引き継ぐのみ） | フリー視点の XYZ スライダーを追加 |
| U4 | エラーが Debug 欄の最下部にあり、視線が行きにくい | 接続欄の近くへ、またはステータスバーを色付き常時表示に |
| U5 | 数値の単位が一部不明（オフセットは「ワールド単位」だが何基準か） | ツールチップで「プレイヤー基準点からの相対」と明記 |

## 4. 既知の制約（設計上のもの）

* GUI は PINE のクライアント枠を 1 つ占有する。**GUI 起動中は `tools/e2e.py` などの外部ツールが接続できない**。
* ステータスバーのメッセージは 8 秒で自動消去（意図的）。恒久的な異常は Debug 欄に残す。
* ウィンドウは 1 枚のみ。マルチモニタやDPIスケーリングは Qt 既定に任せている。
