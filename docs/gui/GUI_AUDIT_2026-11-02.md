# GUI audit — 2026-11-02

Scope: `gui/camera_controller/` (app.py, i18n.py) and the code it depends on (`core/controller/sources.py`,
`core/config/settings.py`, the adapters' GUI-facing attributes). Method: read the code, render the
window, run the live checks. "Fixed" means fixed in the commit that adds this file and covered by
`tests/test_gui.py` or the live checks named in the last column.

## Findings and what was done

| # | Area | Finding | Fix | Check |
|---|---|---|---|---|
| 1 | Robustness | A second GUI (or a script) on the same PINE port made both time out; nothing warned | single-instance lock at start-up with a clear message | `test_gui` |
| 2 | Robustness | Unhandled exceptions in slots (e.g. a PINE write after PCSX2 died) printed to a console nobody sees | every slot that touches the game is wrapped; failures go to the notice bar and `gui.log` | `test_gui` |
| 3 | Robustness | Arrow keys moved the camera whenever the orbit was on, **in any application** (global key state) | keyboard source only reads the keys while PCSX2 or this window is in the foreground | `test_sources` |
| 4 | Robustness | Mouse wheel over a slider changed the camera while scrolling the window | sliders and spin boxes ignore the wheel unless they have focus | `test_gui` |
| 5 | Robustness | Controls stayed enabled with no game / unsupported game / lost link (clicks did nothing) | all camera groups are disabled in those states, with the reason in the notice bar | `test_gui` |
| 6 | Robustness | Pitch slider (±90°) allowed values outside the game's pitch limits | slider range follows the game's limits | `test_gui` |
| 7 | Safety | The saved mode was restored at start-up, so the camera mod switched itself on as soon as a game was seen | the window always starts in Original; the user turns the mod on | `test_gui` |
| 8 | Safety | Loading a preset could switch the mod on or off (the preset carried a mode) | a preset changes values only, never the mode; overwrite asks first | `test_gui` |
| 9 | Consistency | "Disable Camera Mod" and "Restore Original Camera" did the same thing | one button: "Disable and restore the original camera" | `test_gui` |
| 10 | Consistency | Wording fixed to FFX-2 / Yuna on every game (seen earlier), "Stopped"/"Ready" hard-coded English, stage buttons not translated | neutral wording, all strings through the catalogue, language switch retranslates everything | `test_gui` |
| 11 | Game-specific | Offsets were shown (and writable) for games whose adapter ignores them (Shining Force Neo) | offset sliders are disabled with an explanation when the adapter says it cannot use them | `test_gui` |
| 12 | Game-specific | Sign conventions differ per game (look height, pitch) and nothing said so | one-line hint under the sliders, from the adapter (`LOOK_HEIGHT_POSITIVE_IS`, `PITCH_POSITIVE_IS`) | `test_gui` |
| 13 | Game-specific | Offset range ±80 for every game although distances differ 10-fold | per-adapter `OFFSET_RANGE` | `test_gui` |
| 14 | Game-specific | The Free Camera radio is meaningless for 2 of 3 games (handled before) | disabled with a tooltip; window title shows the game name | `test_gui` |
| 15 | UX | Warnings were at the bottom, inside Debug, in red, and the benign "not a field camera" looked like an error | one notice bar under the connection box, with plain-language messages and levels | `test_gui` |
| 16 | UX | 8 offset sliders always visible, window about 900 px tall; clipped on small screens | offsets in a collapsible group (marked when non-zero), debug collapsed, the content scrolls | screenshot |
| 17 | UX | Manual patch buttons (advanced) always visible next to the status | behind "Show advanced" | screenshot |
| 18 | UX | No tooltips on most controls | tooltips on every control that needs one, in both languages | `test_gui` |
| 19 | UX | Yaw slider ±720° although the runtime wraps to ±180° | ±180° | `test_gui` |
| 20 | Performance | The 80 ms refresh re-set every label and style sheet each tick | labels are only touched when their text changes | – |
| 21 | Persistence | "R1 steps the orbit distance" was not remembered | saved per game (`zoom_follow`) | `test_gui` |
| 22 | Dead code | Unused imports, a leftover `_slow_poll` | removed | – |

## Not changed (decided)

* The two-language catalogue stays a plain dict (no Qt Linguist).
* No dark-theme palette work; the colours used are the standard severity colours on the system palette.
* No keyboard shortcuts were added (risk of firing while typing in a spin box).
