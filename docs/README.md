# Documentation index

Hand-written documents live here. Numbers generated by scripts (`reports/*.json`,
`reports/SUIKODEN5_STATE_DIFF.md`) stay in `reports/`. Screenshots, RAM dumps, savestates,
decompiler output and game images are **never** in this repository (see the repository policy in
the top-level `README.md` §10); documents refer to them only by local path.

## Local data (not included)

For code that uses [the path settings](../core/config/paths.py), the base defaults to the checkout's parent directory. Override it with `PS2_LAB_DIR` or `lab_dir` in `config/local_config.json` ([example](../config/local_config.example.json)). Environment variables take precedence over that file; the paths below are relative to the configured base.

| what | where (default) | how to change |
|---|---|---|
| game images, BIOS | `pcsx2/iso`, `pcsx2/bios` | `PS2_GAME_DIR`, `PS2_BIOS_DIR` |
| savestates | `sstates/` | `PS2_SAVESTATE_DIR` |
| extracted states, dumps, Ghidra projects, decompiler output | `work/` | `PS2_DUMP_DIR` |
| screenshots and test evidence | `test_evidence/` | `PS2_EVIDENCE_DIR` |
| backup of the lab documents before they were moved here | `backups/docs_before_migration_20261102/` | – |

## Conventions

* One document per topic; addresses and function names are fine, game code and assets are not.
* A claim about the game needs the way it was checked (state diff, watchpoint, live read-back).
* New game: `docs/games/<game>/CAMERA.md` (analysis) and `TEST_RESULTS.md` (what ran and passed).
* Dates are absolute (`2026-11-02`).

## AGENTS.md in the development lab

The project rules live in [AGENTS.md](../AGENTS.md) at the checkout root. On 2026-11-02 the parent lab used a relative symlink to read the same file. Neither a parent lab nor a symlink is required to run or contribute to this project.
