# FOV 解析と実装

対象: FINAL FANTASY X-2 (Japan) / `SLPS-25250`
最終更新: 2026-10-31

---

## 1. 通常フィールドでの結論（2026-10-31）

試験した通常フィールドでは **`0x340B00` の float 1個**（投影スケール）で画角が変わった。
演出カメラを含む全場面の共通アドレスではない。`other_area_base` で効かなかった理由と投影元を切り替えた後の実測は
[歩行方向調査 §11–12](WALK_DIRECTION_INVESTIGATION.md)、現行版の確認範囲は[技術メモ](ADAPTER_NOTES.md)を参照。

* 値は **毎フレーム再計算されない**（書き換えた値がそのまま残る）
* 書き換えると **実際の描画の視野角が変わる**（カメラ位置は不変）
* 元の値に戻すと完全に復帰する

この測定で変わったのはカメラ位置ではなく投影スケールである。

---

## 2. 発見の経緯

1. 4ステート差分で `0x340B00` が base/left_moved/only_wait で `619.0`、
   `cam_big_moved` でのみ `724.0` であることを確認（カメラ大移動時のみ変化）。
2. 自動スイープ（`scripts/sweep_camera.py`）で +40 したところ、
   描画の 30 % のピクセルが変化 → 描画に効く値であることを確認。
3. 書き込み持続テストで、**フレームを跨いでも値が保持される**ことを確認
   （`writecheck` で 500 ms 後も 660.0 のまま）。
4. 近傍の `0x33F5E0` / `0x33F5F4`（495.2 / 577.733）は毎フレーム再計算される
   派生的な投影値であり、`0x340B00` がその**源**であることを比率で確認。

```
495.2 / 619.0   = 0.800  (= 4/5)
577.733 / 619.0 = 0.9333 (= 14/15)
cam_big_moved:  579.2 / 724.0 = 0.800 , 675.733 / 724.0 = 0.9333
```

**倍率が完全に一致**するため、619 → 724 の変化は「投影全体のズーム」であり、
`0x340B00` がそのマスター値である。

## 3. 角度への換算

投影は 640×448 相当の 4:3 画面に対して

```
sx = x * (0.800 * V) / z + 2048
sy = y * (0.9333 * V) / z + 2048
```

の形で組まれる。水平半角 φ は `tan(φ) = 320 / V`（320 = 640/2）。

したがって本 MOD の FOV は **水平視野角** として

```
FOV_deg = 2 * atan(320 / V)
V       = 320 / tan(FOV_deg / 2)
```

で変換している（`core/camera_math/orbit.py` の `fov_deg_to_scale` /
`scale_to_fov_deg`）。既定値:

| 状態 | V | 水平 FOV |
|---|---|---|
| 通常フィールド（既定） | 619.0 | **54.68°** |
| `cam_big_moved` の場面 | 724.0 | 47.66° |
| GUI 80° 設定時 | 381.4 | 80.00° |
| GUI 40° 設定時 | 879.4 | 40.00° |

安全範囲は **20°〜110°** に制限している（`FOV_MIN_DEG` / `FOV_MAX_DEG`）。
20° 未満では投影行列が破綻してポリゴンが発散し、110° 超では画面端で
幾何が反転するため。

## 4. 実測証拠

E2E-07（`reports/e2e/e2e_results.json`）:

```
fov80_delta  frac_gt16 = 0.5205   ← 80° にすると画面の 52% が変化
fov40_delta  frac_gt16 = 0.5230   ← 40° にすると別方向に 52% 変化
restore_delta frac_gt16 = 0.0225  ← 元に戻すとノイズ床（2%）まで戻る
scale_seen   = 381.36             ← 80° 設定時の実値（320/tan40° = 381.4）
```

カメラ位置（`0x340360`）は FOV 変更中も不変であることを
`tools/e2e.py` の E2E-07 が同時に記録している。
