# RPGツクール5 — PCSX2での確認結果（2026-11-21）

日本版 `SLPS-20143 / BB78C51D`（ディスク1.04）、PCSX2 `v2.7.499-12-g7235a0446`。マップ編集4件とテストプレイ3件の提供ステートを複製し、一時設定のGUI（MainWindow）を接続した。起動時はOriginalで書込み0件。右スティックはGUIの `scripted` 入力でRX/RYを与え、方向キーとR1はPCSX2のパッド割当てをキーボードから操作した。物理パッドを手で操作した試験ではない。

## 中間角と移動追従

基準の2場面では、Originalのままゲーム側の右スティックを倒しても角度・距離は変わらなかった。Orbitへの切替直後も原作の3語は一致。そこからR1を押さず、GUIに一定の右入力 `(RX, RY) = (0.52, 0.20)` を与えた。約70 ms間隔で読んだ8点は両場面ともすべて異なるyawで、45°刻み（raw `0x2000` の倍数）ではなかった。

| 場面・中心 | 描画yaw：開始 → スティックを離した後 | 描画仰角 | 距離 | 方向キー上での注視点：移動前 → 移動後 |
|---|---:|---:|---:|---|
| `base1` 編集・不可視カーソル | 0.00° → 43.28° | 42.19° → 58.84° | 1000 | (1816, 0, 1848) → (1752, 0, 1784) |
| `base2` テストプレイ・操作キャラ | 179.91° → −136.45°（±180°を通過） | 45.00° → 61.72° | 350 | (1752, −32, 1784) → (1816, −32, 1848) |

表の座標はGUIの軸順 `(描画X, 描画Z, 描画Y)`。角度はGUI設定値ではなく、描画された視点と注視点から算出した。移動にはゲーム入力だけを使い、座標は書いていない。移動後もyaw・極角・距離の3語は移動前と一致し、視点と注視点の相対位置の変化は各軸0.05ゲーム単位未満だった。注視点への単位ベクトルと描画行列の前方ベクトルの各成分差は両場面とも `2.1 × 10⁻⁶` 未満。この実測は移動前後の比較で、移動中の全フレーム計測ではない。タイル間の補間経路・軸変換は[解析](CAMERA.md)と[単体テスト](../../../tests/test_rpgmaker5_adapter.py)で別に確認した。

## 水平FOV：レンズ値と画面の両方を比較

同じ位置・角度・距離でGUIの上書きを切り替えた。次の値は両場面で共通。実画角は描画投影行列の水平スケールから換算しており、距離変更によるズームではない。

| GUI | 水平スケール | clip行列の水平成分 | 実水平FOV |
|---|---:|---:|---:|
| 20° | 1448 | 1.448 | 20.052° |
| 40° | 704 | 0.704 | 39.966° |
| 60° | 444 | 0.444 | 59.933° |
| ゲーム値に戻す／Original | 1024 | 1.024 | 28.072° |

両場面の20°と60°の画面を比較した。注視対象とHUDの配置を保ったまま、20°では地形が大きく、60°では周囲まで映る。広角にするとマップ外の青い背景や、地面が描かれない黒い領域が見えることもある。画角の変更を、画面全域で地形が描かれる保証とはしない。

## 復帰・ステート切替

- 両基準場面で、Orbitのまま「ゲーム値に戻す」を押すと角度を保って原作FOVに戻った。その後60°を再適用し、Originalに切り替えた。ロードせずに上表の原作レンズへ戻り、移動先を中心に `(yaw, 極角, 距離)` も取得時の生値（編集 `(0, 17408, 1000)`、テストプレイ `(32768, 16384, 350)`）に一致した。そのまま原作のR1＋方向キー右で両場面ともyawが `−0x2000`（1段）変化した。
- 残る `base1_only_wait`、`base1_cam_moved`、`base1_cam_and_cursor_moved`、`base2_only_wait`、`base2_chara_and_cam_moved` は各々Originalから開始。GUIでyawを31°にすると描画yawは約30.98°になり、Originalで各ステート固有の3語と原作レンズ命令を確認した。[7件の原作値の比較](CAMERA.md#ステートから独立に照合した値)を参照。
- 編集Orbitの最中に未改変のテストプレイ基準をロードした場合は、所有不一致で `unknown` になり、古い編集カメラを書き戻さなかった。Originalを選び直してもロード先の原作値は保たれた。これは**すべてのロードを検知できる**という意味ではない。通常はOriginalに戻してからロードする。

リポジトリの `python -m pytest tests -q` は **2877 passed, 26 subtests passed**。この件数はGUI・アダプター・共通機能のオフラインテストであり、実機試験の回数ではない。

検証用GUIと専用PCSX2は終了し、提供ステート原本7件はすべて開始前のSHA-256と一致した。ステート・メモリ・画面画像は収録していない。全マップ・全作品データ・イベント／メニュー・長時間動作・壁際や地形外の描画は未検証。
